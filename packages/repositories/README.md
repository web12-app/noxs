# repositories/

Reference APT source lists. `bookworm.sources` is the default installed by
RootfsConfigurator; the others are provided for users who switch releases at
their own risk.

| File               | Release            |
|--------------------|--------------------|
| `bookworm.sources` | Debian 12 (default)|
| `trixie.sources`   | Debian 13          |
| `ubuntu.sources`   | Ubuntu 24.04 LTS   |
